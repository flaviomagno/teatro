# Leitor de Ensaio Fuenteovejuna

Aplicação em HTML criada para apoiar o ensaio individual do elenco de **Fuenteovejuna — 2026**.

O leitor permite navegar por personagem, ato e cena e avançar pelas falas de forma progressiva, com apoio das deixas e indicações de emoção.

## Como usar

1. Baixe o arquivo `Leitor_Ensaio_Fuenteovejuna_v20_dialogo_padrao_2026-08-30.html`.
2. Abra o arquivo no navegador.
3. Escolha o personagem, o ato e a cena.
4. Use os controles para avançar e voltar pelas falas.

Não é necessário instalar nenhum programa. O arquivo funciona localmente no navegador.
