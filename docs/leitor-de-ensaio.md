## Para que serve

O **Leitor de Ensaio Fuenteovejuna** foi criado para ajudar no ensaio individual dos atores.

Ele permite navegar por personagem, ato e cena, avançando fala a fala e revelando as deixas do diálogo de forma progressiva. A proposta é aproximar o estudo individual da dinâmica real de cena, em vez de simplesmente reler o texto inteiro.

## Como usar

1. Baixe o arquivo HTML pelo botão abaixo.
2. Abra o arquivo no navegador do computador ou celular.
3. Escolha o personagem, ato e cena.
4. Use os controles para avançar e voltar pelas falas.
5. O leitor funciona localmente: não é necessário instalar nenhum programa.
